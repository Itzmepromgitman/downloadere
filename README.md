# 😈 AnimePahe Soul Harvester (Colab Edition) 🦇

A sinfully fast, elegant Jupyter Notebook to devour episodes from AnimePahe, merge them into your collection, and banish them to the cloud.

This notebook wraps the powerful `animepahe-dl` script directly within Google Colab, leveraging the pristine and premium UI of Ani-Downloader for maximum efficiency and aesthetic dominance.

<a href="https://colab.research.google.com/github/Itzmepromgitman/downloadere/blob/main/animepahe_downloader.ipynb" target="_parent"><img src="https://colab.research.google.com/assets/colab-badge.svg" alt="Open In Colab"/></a>

## ✨ Features
- **Cloudflare Bypass**: Seamlessly sidesteps the `kwik.cx` obfuscated script protection using direct Node.JS integration within Colab.
- **Premium User Interface**: Includes a robust configurations cell in Colab, allowing you to easily set Audio preferences, resolution, and single vs. batch episode ranges.
- **Merge Rituals**: Utilize the power of FFmpeg to merge downloaded episodes seamlessly.
- **Banishment (Cloud Uploading)**: Once the souls (videos) are captured, banish them directly to `GoFile.io` or `Google Drive`.

## 🚀 Usage
1. Click the **Open in Colab** badge above.
2. Run the **Dependencies** cell to prepare the ritual circle (installs `yt-dlp`, `ffmpeg`, `nodejs`, `animepahe-dl`).
3. Fill out the **Devil's Configuration** with your chosen Anime Slug.
4. Execute the final cell to summon the demons and reap the rewards!
